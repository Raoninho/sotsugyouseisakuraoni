## 1. サービス概要

大阪府内でゴルフの練習をする人が、地域と料金を基準に自分に合ったゴルフ練習場を探せるWebサービスです。
複数の施設サイトを行き来しなくても、練習場の所在地、ボール料金、設備などの一覧・詳細画面で確認できることを目指します。
MVPでは大阪府内の一部地域に対象を限定し、10〜20施設程度の情報を掲載します。

---

## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情

私はゴルフが趣味で、普段からゴルフ練習場を利用しています。
普段とは違う練習場で練習したいと思い、新しい練習場を探すことがあります。
練習場を選ぶ際には、料金や営業時間だけでなく、打席数、練習場の距離（ヤード数）、駐車場の広さ、弾道測定器の有無、パター練習場があるかどうかなども気になります。
しかし、練習場によって掲載されている情報が異なるため、複数のWebサイトを確認したり、公式サイトを個別に調べたりする必要があり、手間に感じることがあります。
特に、初めて利用する練習場では、自分が求める設備があるのか、どのくらいの料金がかかるのかを事前に把握できないと不安に感じます。
そこで、ゴルフ練習場の情報を一か所にまとめ、料金や設備を分かりやすく比較し、自分の希望する条件に合った練習場を簡単に探せるサービスがあれば便利だと考えました。

---

### 2-2. なぜそれが「気になった」のか

私はゴルフを楽しむうえで、限られた時間を有効に使い、自分に合った環境で練習することを大切にしています。

同じゴルフ練習場でも、料金や設備、練習できる距離などに違いがあり、練習の目的によって適した施設は変わります。
そのため、単に近くの練習場を見つけるだけでなく、自分の目的や希望する条件に合っているかを比較して選びたいと考えています。

こうした情報を簡単に比較できれば、練習場を探す手間を減らし、より充実したゴルフの練習につなげられると考えました。

---

## 3. 課題の整理（表面的になっていないか）

### 3-1. 表に見えている困りごと

普段はGoogleマップを使って近くのゴルフ練習場を探していますが、自分の希望する条件に合った練習場を簡単に比較できないことです。

---

### 3-2. 本当に解決したい課題は何か

なぜ：自分に合ったゴルフ練習場を探すのが難しいのか？
- 普段はGoogleマップで近くの練習場を探していますが、距離だけでなく料金も考慮して選びたいからです。

なぜ：距離と料金を考慮して選ぶことが難しいのか？
- 練習場ごとに料金を調べる必要があり、家からの距離と料金をまとめて比較するのに手間がかかるからです。

なぜ：比較するのに手間がかかると困るのか？
- できるだけ移動時間や費用を抑えて、気軽にゴルフの練習に行きたいからです。

本当に解決したい課題：
- ゴルフを練習したい人が、家からの距離や料金を簡単に比較し、自分の生活スタイルや予算に合った練習場を迷わず選べるようにすること。

### 4-3. 実際に使われる可能性について(需要・存在確認)

まず最初に使ってくれそうな人は誰か？
大阪府内で定期的にゴルフ練習場に通っている人です。
特に、普段利用している練習場以外にも、自宅から通いやすく、料金が安い練習場がないか探している人を想定しています。

## 8. このアプリの懸念点とその対策

懸念点① 練習場の料金情報の正確性

何が問題になりそうか：
ゴルフ練習場によって料金体系が異なり、平日・休日や時間帯によってボール単価が変わるため、正確な料金情報を掲載し続けることが難しいと考えています。

なぜそう思うか：
練習場の料金が変更されても、サイトの情報が更新されなければ、ユーザーに間違った情報を提供してしまう可能性があるためです。

そのために考えている対策：
ボール単価を「8〜10円／球」のように範囲で表示する
情報の最終更新日を表示する
各練習場の公式サイトへのリンクを設置する
管理画面から料金情報を更新できるようにする


懸念点② ゴルフ練習場のデータ収集

何が問題になりそうか：
大阪府内にあるゴルフ練習場の住所、営業時間、料金、設備などの情報を収集し、データベースに登録する作業に時間がかかることです。

なぜそう思うか：
練習場ごとに公式サイトの情報量や掲載方法が異なり、必要な情報をすべて集めることが難しい場合があるためです。

そのために考えている対策：
MVP段階では大阪府内の一部地域に絞り、10〜20件程度を登録する
公式サイトなどから確認できる情報を優先して収集する
不明な情報は推測で登録せず、「情報なし」と表示する
本リリースでは管理画面を実装し、情報を追加・編集できるようにする

### 10-2. 技術選定の比較検討

| 候補 | 採用/不採用 | 理由 |
| --- | --- | --- |
| Ruby on Rails | 採用  | RUNTEQで学習してきた技術であり、これまでの知識を活かして開発できるため。また、検索機能やユーザー認証などを実装しやすいため  |
| React | 不採用 | フロントエンドの開発に便利だが、今回はMVPの完成を優先し、Railsを中心に開発するため。 |
| PostgreSQL | 採用 | Railsとの相性がよく、練習場・ユーザー・お気に入りなどのデータをリレーショナルデータベースで管理できるため。|
| MySQL| 不採用 | PostgreSQLでも必要な機能を実現できるため、今回はPostgreSQLに統一する。 |
| Render | 採用予定 | Railsアプリを比較的簡単にデプロイでき、インフラ構築よりもアプリの機能開発に集中できるため。 |
| Ransack | 採用 | 地域や料金による検索・絞り込み機能を実装するため。 |
| Geocoder | 採用予定 | 練習場の位置情報を利用し、現在地からの距離計算や距離順検索を実装するため。 |


今回チャレンジしたい点

- Ruby on Railsを利用して、地域からゴルフ練習場を検索できる機能を実装すること
- ボール単価が安い順に並び替える検索機能を実装すること
- 平日・休日それぞれのボール単価を範囲で分かりやすく表示すること
- 練習場ごとの料金や設備を見やすく整理し、比較しやすい画面を作ること
- 実際に利用できるWebサービスとして公開すること

本リリースでチャレンジしたい点

- Geolocation APIを利用してユーザーの現在地を取得すること
- Geocoderを利用して現在地から練習場までの距離を計算すること
- 現在地から距離が近い順に並び替える機能を実装すること
- 平日・休日を指定して、ボール単価が安い順に並び替える機能を実装すること
- Leaflet.jsを利用して地図上に練習場を表示すること

不安な点

位置情報を利用した機能や地図表示の実装は初めてのため、技術的な理解や実装に時間がかかる可能性があります。
また、ゴルフ練習場の住所から緯度・経度を取得する方法や、現在地からの距離を正しく計算する方法についても調査が必要です。
そのため、MVPではRuby on Railsを使って練習場の一覧表示、地域検索、料金比較などの基本機能を優先して完成させたいと考えています。
MVP完成後にGeolocation APIやGeocoder、Leaflet.jsなどの新しい技術を学習し、現在地検索や距離計算、地図表示などの機能を段階的に実装していきたいと考えています。

### 10-3.キャッチアップ不足の懸念

1. 初めて扱う技術への理解不足

今回のアプリでは、RUNTEQで学習してきたRuby on Railsを中心に開発する予定ですが、GeocoderやGeolocation API、Leaflet.jsなど、初めて扱う技術もあります。
特に、現在地の取得や距離計算、地図表示については理解が不足しているため、実装に時間がかかる可能性があります。

- 対策：
MVPでは、Railsを使った練習場の一覧表示、地域検索、料金比較などの基本機能を優先する
現在地取得や距離計算、地図表示は本リリースで実装する
MVP完成後に、GeocoderやGeolocation API、Leaflet.jsについて学習し、段階的に実装する

2. 機能を増やしすぎて完成が遅れること

ゴルフ練習場の検索だけでなく、地図表示やお気に入り登録、口コミなど、追加したい機能が増える可能性があります。

- 対策：
MVPと本リリースで実装する機能を明確に分ける
MVPでは大阪府内の一部地域を対象に、10〜20件程度の練習場情報を登録し、地域検索と料金比較を完成させる
お気に入り機能や地図表示などは、MVP完成後に段階的に追加する
口コミ機能は今後の発展案とし、MVPや本リリースでは優先しない
新しい機能を追加する前に、サービスの目的に本当に必要かどうかを確認する
